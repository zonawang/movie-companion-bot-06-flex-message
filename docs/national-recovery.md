# 全名單來源重檢（2026-10-31）

這次不是只修威秀或親親一個網址。正式 GCP 主機以四個 worker 逐一檢查 108 個已登錄據點，耗時約 243 秒：原版本只有 4 館 `ok`、102 館 `unavailable`、2 館 `links_only`。多數預設頁日期落後，指定日期頁回 HTTP 502 或連線失敗。親親另缺少使用者常用的「親親影城」別名。

## 調整內容

- 保留原來源及原有大巨蛋備援，將場次通從一館擴到逐館核對的 64 館，包括威秀所有已登錄分館及 MUVIE。網址與名稱有明確對照，不用同品牌其他館頂替。沒有版本欄位時保留未標示，0 部電影不解讀為停映或售完。
- 全 108 館都有已配對的 Reelax 公開分館識別與入口，可在一般使用者查詢時備援。只解析頁面本來給瀏覽器的 JSON 資料，不執行頁面 JavaScript。核對 h1、MovieTheater 身分、來源戲院 ID、完整日期與每一筆時間；不使用模型猜資料或以搜尋摘要組合時刻。
- Reelax 僅用於單次使用者查詢，不新增定時整站擷取。讀取限制為兩個同時請求、最多兩個等待請求；每次延遲半秒、連線最多五秒、回應兩 MB。快取五分鐘、失敗冷卻三十秒，逾期資料不在失敗時回傳。此來源不是官方 API，可能缺少版本與臨時異動，來源整理時間不稱為官方更新。
- 親親優先讀官方公開頁，補「親親影城／台中親親」別名，核對日期分頁與片名／版本。依官方時序中明確跨越午夜的時間序列，把凌晨場保留在實際次日；不混成今天晚間。
- 桃園光影讀政府網站完整年月的日曆與每部電影連結中的完整日期；花蓮鐵道讀官方「本週放映」，以近期發布時間核對年份與週期；內惟讀官方月曆的完整年月、連續日序及電影欄位，避免錯信頁面錯置的月份 CSS 標記。
- 中壢光影、中山73、嘉年華目前沒有可穩定自動解析的當日片單，改為清楚的官方入口卡片。這三館的逐場資料尚未完成，沒有宣稱「全部電影場次都可取得」。
- 金獅影城有暫停營業公告，查詢先顯示營運確認卡，不用第三方仍保留的資料宣稱正在放映。
- 使用者的 Google ADK `cinema_schedule`／`cinema_compare` 工具、台灣日期、晚間時間篩選、十張電影卡片與下一批功能沿用。來源故障、未公告、純入口、營運待核對分開表達。

## 查核範圍與限制

108 是現有名單，不是對全台每一個新開、停業、影展或特別放映場所的永久保證。第三方目錄的 111 條與現有 108 條逐一對照；另外三條不是確認的新營運據點，沒有直接擴成 111 館。先前來源頁檢視找到 100 個具有當日結構化場次的公開頁，另有 11 條沒有可讀場次（含三個額外條目）。這是當次「來源頁資料存在」的查核，不能等同全部 runtime 解析與營運狀態均已通過。

場次通的第一輪正式主機查核為 61/64 可讀，另兩館只是省略版本欄位，已修解析；永和當次頁面明示 0 部電影，保留其他來源備援。藝文館不是每天有放映，官方月曆尚未列當日電影時應回未公告與入口，而不是連線失敗或斷言沒有電影。

## 驗證

`test/national-recovery.test.mjs` 覆蓋 108 個識別對照、來源與日期不符、時間格式、僅解析 JSON 不執行腳本、限流與大小限制、快取失效、親親名稱與跨午夜、藝文年／月／週期核對，以及官方入口／營運公告卡片。

全台自動巡檢不應對限制大量自動擷取的第三方建立全站爬蟲。一般查詢的第三方備援以個別實測與完整的識別／日期測試核對，第一方及可巡檢來源則保留逐館結果。實際部署與驗證紀錄於上線後補入。
